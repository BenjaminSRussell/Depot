# What's new

Changes to Depot in plain language, newest first. Add an entry here for every change a user will notice. The "What's new" page in the app shows this file.

## 2026-11-18

- Admin, then Sequences lists the number sequences of each legal entity, with their format and whether their numbers are gap-free. You can't create or change sequences there yet.
- Admin, then Import / export opens the same import as the setup guide: download a template, preview the rows with what to fix in each, then start the import.
- Pages that aren't built yet, such as Audit, Alerts, Documents, Standard texts, the job monitor, the workflow designer and message templates, now say so instead of showing an empty list or made-up rows. Audit is no longer in the Administration workspace.

## 2026-11-10

- The PDF of a purchase order, invoice or packing slip now shows the vendor's or customer's address, prints names in Polish, Czech, Greek, Cyrillic and other European alphabets, numbers every page and repeats the table header on each page.
- Every page now has a "?" button at the top right. It opens a panel that says what the page is for, lists the common tasks and links to the full guide.
- Lists of purchase orders and vendor invoices can be filtered, sorted, saved as views and exported to CSV.
- Vendor invoices show a due date and whether the invoice matches the receipt.
- Accounts payable: you can put every payment to a vendor on hold with a reason and release it again, a proposal that is running, paid or failed opens its payment run, and a completed run gives a remittance advice per vendor to download.

## 2026-11-03

- My work shows everything waiting for you in one place, with an Open link for each item.
- Products can be put in an item group and marked as tracked by batch, serial number or catch weight.

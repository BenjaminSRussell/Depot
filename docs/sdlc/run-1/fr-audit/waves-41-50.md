nothing executed). Where a capability exists only as a pure rule, a stateless preview endpoint, or a domain function without persistence, it is
rated Partial, never Built. Where a NOT-IMPLEMENTED file is stale against the code (services/hr personnel actions), the code wins and the row says so.
